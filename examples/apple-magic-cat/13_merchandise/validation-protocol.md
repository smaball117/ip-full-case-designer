# Merchandise Validation Protocol

Use this after generating a Coco merchandise board.

Score each category 0–2.

## Character consistency
- face matches approved Coco
- proportions remain recognizable
- signature colors remain stable
- cat identity is preserved

## Product translation
- graphic choice suits the product
- product is not just a poster pasted onto an object
- small products use simpler graphics
- plush / figure construction feels plausible

## Family coherence
- products look like one collection
- logo / palette / symbols are consistent
- there is useful variation across items

## Reference use
- reference logic is visible where intended
- unrelated reference content is not copied
- Coco remains the dominant identity

## Commercial readability
- product purpose is obvious
- shapes are clean
- packaging is legible
- no unnecessary small text

## Decision

- **18–20**: strong enough for final case
- **14–17**: targeted revisions
- **10–13**: rethink asset routing or product mix
- **below 10**: regenerate from the merchandise concept, not by adding more decoration

## Repair order

When something fails, fix in this order:

1. wrong character anchor
2. wrong asset type for product
3. inconsistent palette / logo
4. too much decoration
5. presentation-board layout

Do not start by making the prompt longer.
