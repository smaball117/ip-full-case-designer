# Coco Merchandise Plan v0.1

Status: **ready for reference input + first visual test**

This is the first merchandise validation stage for the Coco project.

The goal is not to create a random catalog.
The goal is to test whether the existing Coco assets can be translated into a coherent product family.

---

# 1. Merchandise theme

## Working theme
**可可的愿望寄存处 / COCO'S WISH CHECK-IN**

Why this theme:
- already connected to Coco's world;
- gives the apple symbol a functional role;
- supports packaging, tags, badges and collectible objects;
- can extend naturally into offline pop-up later.

---

# 2. First product family

Keep the first family focused.

## M01 — Collectible figure
Use:
- CC-3D-001

Focus:
- flocked material
- big-head small-body proportions
- apple wand
- star-eye identity

Do not:
- redesign face
- enlarge props too much

---

## M02 — Plush

Use:
- CC-3D-001 as identity anchor
- simplified silhouette translation

Focus:
- oversized head
- short limbs
- clear cat ears
- easy-to-sew shapes
- apple / bow as soft attachments

Do not:
- copy 3D details literally
- use too many tiny parts

---

## M03 — Acrylic stand

Use:
- CC-2D-001

Focus:
- flat full-body Coco
- one wish apple
- simple star / apple base

Optional:
- transparent blue or cream acrylic layers

---

## M04 — Badge / Pin set

Use:
- Coco face
- apple
- star
- bow

Suggested set:
1. Coco face
2. success apple + star
3. green failed apple
4. bow / wand symbol

This stage tests whether the IP can work without full-body art.

---

## M05 — Keychain

Use:
- face icon
- apple icon
- small full-body Coco

Prefer:
- one main charm + one small secondary charm
- simple shape
- clear silhouette

---

## M06 — Sticker sheet

Use:
- expression assets
- action assets when available
- apple state icons

Suggested sticker logic:
- 4–6 Coco poses
- 2 apple states
- 1 star reward
- 1 logo sticker

No random filler text.

---

## M07 — Tote / pouch

Use:
- 2D flat art
- Hi Coco logo
- apple / star repeat pattern

Test three graphic scales:
- large central character
- small chest-style mark
- repeat pattern

Do not put the same full-body art on both tote and pouch.

---

## M08 — Blind-box / gift packaging

Use:
- CC-LOGO-001
- CC-2D-001
- apple / star / bow symbols

Focus:
- clean sky-blue / apple-red / cream palette
- strong title
- minimal supporting text
- clear collectible identity

Avoid:
- dense microcopy
- overdecorated children's packaging

---

# 3. Asset routing

```text
3D Character Final
→ figure

Character silhouette
→ plush

2D full body
→ acrylic stand / tote

Face + icon
→ badge / keychain

Expression / action
→ sticker sheet

Logo + symbols
→ packaging / labels / pattern
```

The same full-body Coco should not appear on every item.

# 5. First visual test

Recommended first board:

**8-product merchandise family board**

Products:
1. figure
2. plush
3. acrylic stand
4. badge set
5. keychain
6. sticker sheet
7. tote / pouch
8. blind-box packaging

Visual direction:
- clean cream or sky-blue presentation background
- apple red as identity accent
- no unrelated decorative props
- each product visually separated
- no dense small text

---

# 6. Validation questions

After the first board, review:

1. Does every item still read as Coco?
2. Are the products varied, or is the same character simply pasted everywhere?
3. Is the face consistent with CC-3D-001?
4. Are colors stable?
5. Is the apple symbol used meaningfully?
6. Does the packaging feel like the same IP as the character?
7. Which products look commercially believable?
8. Which ones need a dedicated production asset first?

---

# 7. Expected outcome

After this stage, keep only the strongest 4–6 products for the final case.

The purpose is not quantity.

The purpose is to prove:
**Coco can expand from a character into a coherent IP product family.**
