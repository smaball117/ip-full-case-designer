# 3. Why Coco is the canonical template example

Coco reflects the intended real workflow:

1. user starts with an idea;
2. user feeds references gradually;
3. Agent generates several creative directions;
4. user selects and corrects visually;
5. approved character becomes the anchor;
6. new references are introduced for outfit, flat style, logo, poster, merchandise and space;
7. the Agent keeps extending the same IP instead of restarting.

This is the default behavior new IP projects should follow.
