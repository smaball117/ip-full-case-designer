# 可可 / Coco — Apple Magic Cat

This is the first real test project for `ip-full-case-designer`.

It is no longer only a scaffold. It records an actual reference-driven IP development process.

## Project premise

可可是一只在魔法学院学习收集愿望的奶油白小猫。

- 苹果 = 愿望收集器
- 一件事情真正完成后，苹果里亮起一颗星
- 失败时苹果变成青色
- 可可性格：勇敢、贪吃、粘人
- 成功后偶尔会用一点魔法变出小甜点庆祝
- 目标人群：年轻女性

## Current character anchor

Current operational character:

- cream-white cat
- oversized head / tiny body
- clear triangular cat ears
- large brown-gold cat pupils
- star-shaped eye highlights
- small expressive eyebrows
- red apple-themed magic hat
- red cape with cream-yellow trim and pale-blue lining
- small apple wand
- flocked / velvety collectible-toy material
- props remain secondary to the face

## Current poster lesson

Poster testing exposed an important Skill issue:

A reference can be visually strong, but the Agent must not reduce the task to:

```text
reference poster → replace original character with Coco
```

The correct behavior is:

```text
user theme + reference intent + approved Coco anchor
→ analyze what to inherit
→ control density and hierarchy
→ create a Coco-specific result
```

Recent poster feedback:
- too many elements feels crowded;
- Coco should remain the visual focus;
- large clean negative space is useful;
- unnecessary microcopy should not appear;
- if a result is too close to the reference, change the concept structure rather than tiny decorations.
