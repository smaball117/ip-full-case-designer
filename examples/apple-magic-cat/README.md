# Apple Magic Cat — Test Project

This is the first end-to-end test case for `ip-full-case-designer`.

## Current seed

- cream-white cat
- red apple
- bow
- magician / magic apprentice
- cute 3D collectible toy
- oversized head, tiny body
- low-positioned facial features
- small expressive eyebrows
- soft pink facial gradients
- small accessory-scale props
- soft vinyl / resin material

## Purpose

Use this project to test the workflow in practice:
1. five concept directions;
2. deep brief;
3. five sketch explorations;
4. Character Master;
5. turnaround;
6. expression/action system;
7. outfit translation;
8. 2D assets;
9. visual identity;
10. campaign;
11. merchandise;
12. offline;
13. review.

The example is intentionally not marked complete. It should evolve as the skill is tested.
