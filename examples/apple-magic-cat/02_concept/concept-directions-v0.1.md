# Apple Magic Cat — Concept Directions v0.1

Status: **Gate A — waiting for selection**

Current seed:
- cream-white cat
- red apple
- bow
- magician / magic apprentice
- oversized head, tiny body
- low-positioned facial features
- small expressive eyebrows
- soft pink gradients
- soft vinyl / resin collectible-toy language

The five directions below intentionally differ in world premise, character motivation, symbol meaning, behavior, and commercial extension. They are not color swaps.

---

## Direction A — Wish Keeper / 愿望收藏师

### One-line premise
一只负责收集“没有被说出口的小愿望”的白猫魔法学徒，把每个愿望封存在红苹果里。

### Character role
愿望收藏师 / 小型愿望保管员。

### Personality
- 温柔
- 有点胆小
- 很认真
- 容易替别人担心
- 被夸时会偷偷得意

### Useful flaw
它总想把每个人的愿望都照顾好，所以经常把自己的愿望忘掉。

### Apple meaning
红苹果不是普通水果，而是“愿望容器”。苹果越红，代表愿望越强烈。

### Recurring behavior
- 把耳朵贴近苹果听愿望
- 给苹果系上蝴蝶结分类
- 用魔法棒检查愿望是否成熟
- 把实现的愿望放飞成小星星

### Visual keywords
soft wish magic / ribbon tags / tiny stars / apple archive / gentle ritual / warm cream + apple red

### Commercial extensions
- 愿望卡
- 许愿苹果挂件
- 节日限定愿望系列
- 生日礼赠
- 情绪贴纸
- 快闪“愿望交换所”

### Tradeoff
情绪连接很强，但魔法师的“奇幻冒险感”会比较弱，整体偏治愈。

## Direction B — Apple Alchemy Apprentice / 苹果炼金学徒

### One-line premise
白猫在苹果炼金学院学习把不同情绪炼成魔法，但它的配方经常出现可爱的小意外。

### Character role
炼金学徒 / 情绪配方实验员。

### Personality
- 好奇
- 笨拙
- 执着
- 有点冒失
- 失败后会马上重来

### Useful flaw
理论成绩很好，但每次真正施法都容易“多加一颗苹果”。

### Apple meaning
苹果是基础魔法原料，不同颜色或状态的苹果代表不同情绪与效果。

### Recurring behavior
- 搅拌苹果魔药
- 记录失败配方
- 因爆炸变成炸毛脸
- 偷偷尝试新配方

### Visual keywords
mini alchemy / round flask language / tiny potion props / apple ingredients / playful laboratory / candy chemistry

### Commercial extensions
- 系列盲盒
- 魔法配方卡
- 实验室主题包装
- 文具
- “今日情绪配方”社交内容
- 快闪“苹果炼金研究所”

### Tradeoff
故事延展和周边很强，但需要控制实验室元素，避免角色被过多道具淹没。

## Direction C — Lucky Apple Guardian / 幸运苹果守护者

### One-line premise
白猫守护着一棵只会在“好运靠近时”结出红苹果的魔法树。

### Character role
苹果树守护者 / 小幸运分发员。

### Personality
- 热心
- 正义
- 有点神气
- 行动力强
- 很相信自己的直觉

### Useful flaw
它总觉得自己能预测好运，但其实经常只是“刚好猜对”。

### Apple meaning
苹果是好运信号。成熟苹果可以被送给需要一点勇气的人。

### Recurring behavior
- 巡逻苹果树
- 给别人递幸运苹果
- 发现果实变红时兴奋跳起来
- 把坏心情埋进土里

### Visual keywords
lucky charm / magical orchard / apple badge / protective cape / bright optimistic red / outdoor fantasy

### Commercial extensions
- 幸运挂件
- 护身符徽章
- 开学/考试/新年主题
- 户外快闪
- 幸运抽签互动
- 小型花园装置

### Tradeoff
识别和商业吉祥寓意都很直接，但需要避免落入普通“好运吉祥物”套路。

## Direction D — Apple Oracle / 苹果星象师

### One-line premise
白猫通过苹果表面的微光读取人的情绪星轨，并把无法说清楚的心情翻译成星象。

### Character role
情绪星象师 / 苹果占星学徒。

### Personality
- 安静
- 敏感
- 神秘
- 观察力强
- 偶尔一本正经地说错答案

### Useful flaw
太相信自己的星象判断，所以有时会把“饿了”误判成“宇宙波动”。

### Apple meaning
苹果是小型星象水晶球，内部可以看到星星、轨迹和情绪颜色。

### Recurring behavior
- 对着苹果观察星轨
- 记录当天情绪天气
- 把小星星收进帽子
- 预测结果后偷偷观察别人反应

### Visual keywords
crystal apple / tiny orbit / quiet magic / soft glow / celestial symbols / collectible dreamy toy

### Commercial extensions
- 星座/月份系列
- 情绪测试内容
- 水晶苹果摆件
- 夜光周边
- 收藏级手办
- “苹果星象馆”沉浸式空间

### Tradeoff
收藏感和高级感最强，但如果光效太多会偏离你现在喜欢的克制软胶风。

## Direction E — Apple Dessert Magician / 苹果甜点魔术师

### One-line premise
白猫会把普通苹果变成让人开心的微型甜点魔法，每次表演都像一场小小的庆祝。

### Character role
甜点魔术师 / 快乐制造员。

### Personality
- 活泼
- 贪吃
- 爱表演
- 有点臭美
- 很会哄人开心

### Useful flaw
每次说“只尝一口”，最后都会把试作品吃掉一半。

### Apple meaning
苹果是魔法甜点的核心原料，也是角色的表演标志。

### Recurring behavior
- 从帽子里变出苹果甜点
- 偷吃作品
- 失败时冒出奶油泡泡
- 给朋友做迷你苹果派

### Visual keywords
dessert magic / red bow / tiny pastry props / celebration / playful stage / sweet collectible

### Commercial extensions
- 食品联名
- 咖啡店联名
- 甜点包装
- 餐具
- 节日礼盒
- “苹果魔法甜点屋”快闪

### Tradeoff
最容易商业联名，也最活泼，但会弱化你现在白猫身上的安静、柔软气质。

# Gate A comparison

| Direction | Strongest strength | Emotional tone | World scalability | Merchandise | Offline |
|---|---|---|---|---|---|
| A Wish Keeper | emotional bond | gentle / healing | high | high | wish exchange |
| B Alchemy Apprentice | story/action | curious / playful | very high | very high | magic lab |
| C Lucky Guardian | simple recognition | bright / optimistic | medium-high | high | outdoor orchard |
| D Apple Oracle | collectible atmosphere | quiet / mysterious | high | high | immersive gallery |
| E Dessert Magician | commercial collaboration | lively / sweet | high | very high | dessert shop |

## Gate A decision rule

Choose one direction, or explicitly combine **at most two** directions with clear ownership.

Good example:
- "A为主，保留B的炼金配方行为"

Avoid:
- "五个都要"

Too many directions at once will weaken the IP core.
