# Prompt Record

**Asset ID:** JSG-POST-001  
**Stage:** 12_posters  
**Version:** v0.1  
**Status:** planned

## Goal

Create the first primary vertical campaign KV for Jellyfish Star / 水母星守.

The poster must feel like a premium collectible-toy campaign image, not a busy fantasy illustration.

## Locked identity

- approved Jellyfish Star Guardian character
- transparent blue-violet jellyfish dome
- warm stars inside dome
- lavender hair
- blue-violet eyes
- blue-violet base costume language
- crescent/star/jellyfish visual vocabulary
- current logo direction

## Composition rule

Visual priority:

1. character
2. one story symbol
3. atmosphere
4. title

Background must not compete with the character.

Maximum **3 background element categories**.

## Canonical prompt

```text
Create a premium 3:4 vertical campaign poster for the collectible-toy IP “Jellyfish Star / 水母星守”.

CHARACTER:
use the approved 3D jellyfish guardian girl;
same transparent blue-violet jellyfish dome;
same warm star inserts;
same lavender hair;
same large blue-violet eyes;
same compact Q-version proportions;
same real-world collectible-toy material language.

POSE:
gentle floating / light stepping pose;
character slightly below center;
moderate character scale with generous breathing room;
clear silhouette;
not oversized.

STORY SYMBOL:
one large soft crescent moon placed behind or beside the character;
the crescent acts as a quiet compositional anchor, not decoration overload.

BACKGROUND:
deep blue-violet dreamy night-to-water atmosphere;
maximum 3 background element categories:
1. crescent moon
2. soft cloud / mist mass
3. very sparse bubbles or star lights
keep all background elements low-detail, soft-focus and lower contrast than the character.

GROUND:
subtle reflective water surface or simple translucent base only;
no complex environment.

LIGHTING:
soft commercial product-photography light;
warm moonlight + cool blue-violet fill;
clean highlights on transparent dome;
controlled glow, no heavy bloom.

TYPOGRAPHY:
working title only:
“Jellyfish Star”
“水母星守”
place title in upper-left or lower-left negative space;
no microcopy;
no slogan;
no decorative filler text.

STYLE:
high-end collectible-toy campaign photography;
clean;
dreamy;
quiet;
premium;
not childish;
not crowded.

OUTPUT:
3:4 vertical poster;
single hero character;
minimal composition;
large negative space.
```

## Negative / Do not

- no full fantasy city
- no coral forest
- no dense stars
- no many bubbles
- no random props
- no extra characters
- no many glowing ornaments
- no tiny decorative text
- no busy border
- no giant character filling the frame
- no 2D illustration

## Repair rule

If crowded:
1. remove background elements first;
2. keep only moon + one atmospheric layer;
3. do not enlarge the character as the first fix.

If weak:
1. increase silhouette separation;
2. simplify the background;
3. strengthen the moon/character relationship.
