# Prompt Record

**Asset ID:** JSG-MERCH-001  
**Stage:** 13_merchandise  
**Version:** v0.1  
**Status:** planned

## Goal

Build a coherent first merchandise family for Jellyfish Star / 水母星守 using different approved IP assets for different product types.

The result should feel like a real collectible-IP product line, not the same full-body character pasted onto every item.

## Locked IP assets

Use:
- approved 3D hero character
- approved 2D flat assets
- approved logo direction
- jellyfish companion
- star / moon / bubble icons
- approved blue-violet / lavender / warm cream-yellow palette

## Asset routing

### 1. Blind-box figure
Use:
- 3D hero character
- simplified collectible-toy materials
- minimal base

### 2. Plush
Use:
- simplified silhouette
- jellyfish dome translated into soft fabric construction
- reduced decoration

### 3. Acrylic stand
Use:
- one clean 2D full-body character
- transparent acrylic edge
- simple shaped base

### 4. Badge / pin set
Use:
- face icons
- star
- jellyfish companion
- crescent moon

### 5. Keychain / charm
Use:
- jellyfish companion
- star
- crescent moon lantern
- small character head charm

### 6. Sticker sheet
Use:
- 2D expression assets
- icons
- small companion
- no long text

### 7. Tote / pouch
Use:
- one simplified 2D illustration or repeat pattern
- logo small and secondary

### 8. Blind-box / gift packaging
Use:
- logo
- 2D character
- star / jellyfish pattern
- large breathing room
- clean product hierarchy

## Material realism

Use physically plausible product materials:
- PVC / ABS / resin for figures
- polyester plush / short pile fabric for plush
- acrylic for standee / charms
- enamel / metal for pins
- paperboard for blind-box packaging
- coated paper for stickers
- canvas / cotton-poly blend for tote
- zinc alloy / plated metal for key rings

Do not invent impossible fantasy materials.

## Canonical prompt

```text
Create a premium merchandise presentation board for the collectible IP “Jellyfish Star / 水母星守”.

STYLE:
clean commercial product photography;
soft blue-violet studio setting;
large whitespace;
premium but cute;
realistic manufacturable materials;
consistent brand palette;
no clutter.

PRODUCT FAMILY:
1 blind-box PVC figure
1 simplified plush
1 acrylic stand
1 badge/pin set
1 keychain/charm set
1 sticker sheet
1 tote or pouch
1 blind-box / gift packaging

ASSET ROUTING:
do not repeat the same full-body image on every product.
Figure uses the approved 3D hero.
Plush uses a simplified silhouette.
Acrylic stand uses one clean 2D full-body asset.
Pins use face icons, star, moon and jellyfish companion.
Keychains use small symbols and companion characters.
Sticker sheet uses expressions and mini icons.
Tote uses one flat illustration or repeat pattern.
Packaging uses logo + character + pattern with clear hierarchy.

BRAND ELEMENTS:
transparent jellyfish dome;
warm stars;
lavender hair;
blue-violet palette;
crescent moon lantern;
small jellyfish companion;
minimal bubbles.

MATERIALS:
PVC / ABS / resin figure;
polyester plush;
clear acrylic;
enameled metal pins;
zinc-alloy key rings;
paperboard box;
coated sticker paper;
canvas tote.

COMPOSITION:
3:4 vertical merchandise board;
products clearly separated;
no dense decorative scenery;
background only as a restrained studio set;
maximum 2–3 supporting background elements;
no unrelated props.

TYPOGRAPHY:
working logo only where needed;
no random microcopy;
no fake slogans.

OUTPUT:
coherent, believable, retail-ready merchandise family.
```

## Negative / Do not

- no same full-body character repeated on every product
- no overloaded package graphics
- no fake luxury materials
- no impossible transparent fabric merchandise
- no random text
- no dense decorative scene
- no extra unrelated products
- no excessive stars and bubbles

## Review criteria

The board passes only if:
- each product uses the appropriate asset type;
- the family is visually coherent;
- product materials look manufacturable;
- the character remains recognizable;
- packaging and tote do not become illustration posters;
- the board is clean enough to evaluate products individually.
