# Prompt Record

**Asset ID:** JSG-2D-001  
**Stage:** 10_2d_assets  
**Version:** v0.1  
**Status:** planned

## Goal

Translate the approved Jellyfish Star Guardian from 3D collectible-toy language into a clean, reusable 2D flat illustration system for stickers, badges, packaging, posters and small merchandise.

## Locked identity

- transparent jellyfish dome remains the strongest silhouette cue
- 3–5 warm cream-yellow stars inside the dome
- lavender hair
- large blue-violet eyes
- compact Q-version proportions
- blue-violet + lavender + warm cream-yellow palette
- crescent / star / jellyfish visual vocabulary
- gentle, dreamy, curious guardian personality

## Translation rule

Do not imitate the 3D render literally.

Convert:
- transparent dome → simple translucent color block / pale gradient-free overlay
- glossy resin highlights → 1–2 clean highlight shapes only
- pearlescent material → flat light-value contrast
- complex ruffles → simplified 2–3 layer silhouette
- tiny beads / chains → remove or reduce to a single icon accent
- realistic reflections → no reflections, only simple shape language

## Canonical prompt

```text
Create a clean 2D flat illustration asset sheet for the approved Jellyfish Star Guardian IP.

LOCK CHARACTER:
same transparent jellyfish-dome silhouette;
same lavender hair;
same large blue-violet eyes;
same compact Q-version body proportions;
same blue-violet base outfit;
same warm cream-yellow star symbols;
same gentle dreamy guardian personality.

FLAT STYLE:
simple clean shapes;
smooth rounded silhouette;
thin warm violet or muted indigo outline;
solid color fills;
no gradients;
no painterly shading;
no 3D lighting;
no glossy reflections;
no texture noise;
minimal highlight shapes only;
commercial sticker / packaging illustration quality.

SIMPLIFY:
reduce transparent jellyfish dome to one clean translucent blue-violet shape;
keep only 3–5 star icons inside;
simplify dress layers to 2–3 readable shapes;
remove unnecessary pearls, chains, micro-jewelry and tiny decoration;
keep the face expressive and easy to read at small size.

ASSET SET:
1. full-body standard pose
2. floating pose
3. sitting / resting pose
4. sleeping pose
5. close-up face icon
6. small jellyfish companion
7. crescent moon lantern icon
8. star / bubble mini icons
9. one simple pattern unit combining jellyfish + star

COMPOSITION:
3:4 vertical asset board;
clean off-white / very pale blue background;
generous spacing;
each asset isolated and easy to cut out;
no decorative scene;
no text.

OUTPUT:
coherent flat IP asset family ready for stickers, badges, packaging and posters.
```

## Negative / Do not

- no 3D rendering
- no gradients
- no painterly effects
- no photoreal materials
- no complex background
- no dense decoration
- no text
- no random new costume
- no redesign of face or head/body ratio

## Repair rule

If the flat version still feels like a rendered 3D toy:
1. remove highlights and shadows;
2. reduce detail count;
3. simplify silhouette;
4. keep only 3–5 color blocks per asset.

If it becomes too generic:
1. enlarge the jellyfish-dome silhouette;
2. restore the warm star inserts;
3. preserve lavender hair and blue-violet eye identity.
