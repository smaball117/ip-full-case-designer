## Canonical prompt

```text
Create a premium Q-version collectible-toy figure of a deep-sea jellyfish guardian girl.

CHARACTER:
large rounded transparent jellyfish dome;
short lavender hair;
large blue-violet eyes;
small compact body;
short layered blue-violet dress;
small crescent-moon lantern in one hand.

DOME CONSTRUCTION:
clear cast resin or transparent PVC dome with a soft scalloped rim;
inside the dome, place 3–5 separate warm cream-yellow star inserts;
only a few tiny sparkle points;
no galaxy texture filling the entire dome.

MATERIALS:
face and body: matte painted PVC;
hair and opaque costume parts: painted PVC with satin finish;
transparent dome and translucent dress edges: clear resin / transparent PVC;
lantern frame: gold-tone plated plastic;
lantern globe: clear acrylic or clear resin;
warm luminous center represented as a display-light effect.

FORM LANGUAGE:
smooth simplified curves;
few parts;
clean molded transitions;
no sharp complicated edges;
no dense jewelry;
no excessive ruffles.

PRESENTATION:
commercial collectible-toy product photography;
soft studio lighting;
clean blue-violet atmospheric background;
character remains the first visual focus;
few supporting objects only.

OUTPUT:
3:4 full-body hero product render.
```

## Negative / Do not
- no 2D illustration look
- no impossible liquid-crystal cloth
- no undefined glowing skin
- no excessive transparent tendrils
- no dense coral / shell set
- no over-detailed costume

## Output
- Ratio: 3:4
- Grid / count: single hero
- Background: clean atmospheric product set
- Text policy: none
- Material / rendering: painted PVC + clear resin / transparent PVC + plated plastic

## Repair notes
- if it looks illustrated, increase product-photography realism and molded-material clarity
- if it looks too complex, remove 30–50% of tiny costume pieces
- if the head feels noisy, reduce internal stars and tendrils

## Learnings
The successful 3D direction depends more on real molded-material logic and simplified curves than on fantasy effects.
