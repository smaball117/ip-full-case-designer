# Prompt Record

**Asset ID:** JSG-OUT-002  
**Stage:** 09_outfits  
**Version:** v0.2  
**Status:** candidate

## Goal

Create a cleaner 3x3 collectible outfit series with real differentiation between looks and restrained backgrounds.

## Locked identity
- transparent star-filled jellyfish dome
- lavender hair
- blue-violet eyes
- Q-version body proportions
- core facial identity
- collectible-toy material logic

## Reference use

### REF-03
**Learn:**
- strong styling changes across a 3x3 collection
- headwear / props / silhouette can vary together

**Do not inherit:**
- source character face
- source wording
- exact clothing

### REF-04
**Learn:**
- each look can have a distinct mood and seasonal identity
- pose and styling should change together

**Do not inherit:**
- exact flower-goddess styling
- original hair / facial construction

### REF-05
**Learn:**
- simple product-scene background
- few large shapes
- negative space
- low detail density

**Do not inherit:**
- source branding or flower props

## Change / explore
Each look changes at least 2–3 of:
- outfit silhouette
- role
- headwear
- footwear
- prop
- mood
- secondary color

## Canonical prompt

```text
Create a 3x3 collectible-toy outfit series for the approved jellyfish guardian girl.

LOCK CHARACTER:
same transparent rounded jellyfish dome with warm star inserts;
same lavender hair;
same blue-violet eyes;
same compact Q-version body;
same face and head/body ratio;
same real-world toy material language.

SERIES RULE:
nine looks must be clearly different in styling, not only color or pose.
Each look changes at least 2–3 meaningful dimensions:
silhouette, layering, role, headwear, footwear, handheld prop, mood, or secondary color.

OUTFIT DESIGN:
translate the theme into simple manufacturable blind-box clothing shapes.
Keep curves smooth and parts limited.
Do not hard-code one repeated ruffle dress.
Allow short cape, sailor styling, rainwear, soft sleepwear, explorer outfit, shell-inspired dress, ceremonial night look, casual ocean look, or other theme-appropriate silhouettes.

BACKGROUND:
not pure color, but very simple.
Maximum 3 background element categories per cell.
Use one main environment cue + one support object + one atmospheric element.
Keep background lower in contrast, saturation, sharpness and detail than the character.
Preserve generous visual breathing room.

MATERIAL:
painted PVC / ABS for opaque parts;
clear resin or transparent PVC for dome and selected translucent details;
fabric-like sculpting only when physically plausible;
small metal-plated accessories allowed.

COMPOSITION:
3:4 total board;
consistent character scale;
clean commercial collectible-series catalog feeling;
character first, outfit second, environment third.

NO TEXT.
```

## Negative / Do not
- no full illustrated scene
- no dense coral forests
- no multiple buildings
- no many floating ornaments
- no same dress repeated 9 times
- no AI-invented impossible materials
- no decorative text

## Output
- Ratio: 3:4
- Grid / count: 3x3 / 9 looks
- Background: simple non-solid, max 3 element categories
- Text policy: none
- Material / rendering: realistic collectible-toy product rendering

## Repair notes
If a cell still feels crowded:
1. remove background objects first;
2. reduce prop count;
3. keep the character scale unchanged;
4. simplify the outfit only after the background is clean.

## Learnings
Strong outfit variation comes from silhouette + role + prop changes.
Strong focus comes from background restraint, not merely enlarging the character.
