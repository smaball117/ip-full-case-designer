# Prompt Record

## Naming status

The current title **Jellyfish Star / 水母星守** is a working name, not a final locked character name.

The logo system should therefore be treated as a visual direction test.

## Goal

Create a clean logo and typography system that feels dreamy, marine, gentle and collectible-toy friendly without becoming childish or overly ornate.

## Reference use

### REF-08 — logo / typography reference slot
Use for:
- lettering rhythm
- softness
- curvature
- symbol integration
- compact mark structure

Do not copy:
- exact glyphs
- source-brand logo
- proprietary symbols

## IP symbols available

- transparent jellyfish dome
- warm star
- crescent moon
- bubble
- tiny jellyfish companion

Use at most **1–2 symbols per logo route**.

## Negative / Do not

- no dense decorative stars
- no many bubbles around lettering
- no unreadable script
- no childish bubble font
- no luxury fashion serif
- no copying source logos
- no random English filler text
- no packaging mockup in this stage

## Learning target

The logo should be identifiable even when the character illustration is absent.
The strongest route should rely on typography + one simple symbol, not decoration.
