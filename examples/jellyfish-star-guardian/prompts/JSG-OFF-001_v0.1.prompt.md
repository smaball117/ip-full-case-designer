# Prompt Record

**Asset ID:** JSG-OFF-001  
**Stage:** 14_offline  
**Version:** v0.1  
**Status:** planned

## Goal

Translate the Jellyfish Star / 水母星守 world into a real-world mall pop-up / exhibition space.

The space should feel like a physical interpretation of the “Dream Trench” world, not a generic booth covered in character graphics.

## World concept

Dream Trench / 梦境海沟:
- quiet deep-sea dream world
- sleeping stars
- gentle glowing jellyfish
- moonlight navigation
- protection, guidance and comfort

## Spatial strategy

Use only three major zones:

1. **Hero installation**
   - one large translucent jellyfish dome
   - one crescent moon / star-light installation
   - approved character as the focal sculpture

2. **Product display**
   - low clean plinths / shelving
   - merchandise grouped by type
   - no dense retail shelving

3. **Photo / interaction zone**
   - one shell / moon seat or star-light interaction
   - simple visitor path
   - one clear photo angle

## Material realism

Use buildable real-world materials:
- frosted acrylic
- translucent polycarbonate / acrylic panels
- painted MDF
- molded fiberglass / FRP for large sculptures
- fabric lightbox / stretched membrane
- LED light strips / diffused light modules
- matte painted metal
- clear acrylic display cases

Avoid impossible liquid architecture or fully transparent unsupported structures.

## Canonical prompt

```text
Create a premium offline pop-up / mall installation concept for the IP “Jellyfish Star / 水母星守”.

CONCEPT:
translate the Dream Trench world into a real buildable retail / exhibition space.

SPATIAL HIERARCHY:
1. one hero installation
2. one merchandise display zone
3. one photo / interaction zone

HERO INSTALLATION:
a large translucent blue-violet jellyfish dome made from frosted acrylic / translucent polycarbonate;
soft warm star lights suspended inside;
one crescent moon light element;
the approved Jellyfish Star Guardian figure/sculpture placed as the visual focal point.

DISPLAY ZONE:
simple low rounded plinths and a few clean shelves;
display blind boxes, figures, acrylic stands and small merchandise;

no dense supermarket shelving.

PHOTO / INTERACTION ZONE:
one sculptural shell or crescent seat;
one warm star light object;
clear open floor around it;
design one strong photo angle.

MATERIALS:
frosted acrylic;
painted MDF;
FRP sculpture;
matte metal;
clear acrylic display;
diffused LED lighting.

COLOR:
deep blue-violet + lavender + warm cream-yellow light;
small amount of off-white;
no rainbow palette.

BACKGROUND / ARCHITECTURE:
mall atrium or clean indoor exhibition hall;

COMPOSITION:
16:9 wide spatial visualization;
front three-quarter view;
clear circulation;
clean negative space;
large simple masses;
premium retail visualization.

BRAND USE:

no dense hanging decorations;
no many small stars;

one coherent offline pop-up concept image,
```

## Review criteria

The concept passes only if:
- the character remains the focal point;
- the space is readable at a glance;
- there are only 3 major functional zones;
- materials are physically buildable;
- the scene does not become an over-decorated fantasy park;
- products can actually be displayed and approached;
- the visitor route is clear.

## Repair rule

If crowded:
1. remove hanging objects first;
2. reduce repeated stars/jellyfish;
3. merge decorative elements into one large sculptural mass;
4. preserve circulation and whitespace.
