# 水母星守 / Jellyfish Star Guardian

This is the second real test project for `ip-full-case-designer`.

It validates whether the Skill can:
- start from a loose idea;
- use references gradually;
- lock a character identity;
- translate that identity into 3D collectible-toy language;
- create varied outfit series;
- keep backgrounds simple enough to preserve subject focus;
- save reusable prompt records for every major visual.

## Core idea

A Q-version deep-sea guardian girl with a transparent jellyfish head.

Inside the transparent jellyfish dome are glowing stars.

She lives in a dreamlike deep-sea trench and patrols the ocean as a gentle guardian spirit.

## Direction

Selected direction:
- **D + E combination**
- lively jellyfish patrol spirit
- dreamy sleeping-star guardian
- 3D collectible-toy presentation

## Current visual anchor

The approved working direction is:

- Q-version girl
- large transparent jellyfish dome
- blue-violet palette
- glowing warm stars suspended inside the dome
- lavender hair
- large blue-violet eyes
- compact small body
- short layered translucent dress
- crescent-moon lantern
- smooth, simplified collectible-toy forms
- materials should map to real production materials

## Current production lesson

The strongest result came from simplifying:

- fewer outfit micro-details;
- fewer tiny decorative objects;
- cleaner curves;
- restrained backgrounds;
- max 3 background element categories;
- lower background detail than the character.

The character does **not** need to fill the frame to remain dominant.
