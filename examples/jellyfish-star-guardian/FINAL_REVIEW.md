> Case status: **complete with open items**

# 1. Final project position

## Core idea

A tiny deep-sea guardian spirit who patrols the Dream Trench with a moon lantern, caring for sleeping stars, dream fragments and lost sea creatures.

She is:
- not a princess;
- not a mermaid;
- not a combat character.

Her emotional core is:

**陪伴 / 照亮 / 守护 / 引路**

## Strongest visual anchors

1. transparent blue-violet jellyfish dome
2. 3–5 warm cream-yellow stars inside the dome
3. lavender hair
4. large blue-violet eyes
5. compact Q-version body
6. crescent moon lantern
7. blue-violet + lavender + warm cream-yellow palette

These should remain stable across future outputs.

# 2. What is approved

## Keep

### Character identity
Approved and reusable:
- Q-version deep-sea guardian girl
- transparent jellyfish dome
- warm stars inside dome
- lavender hair
- blue-violet eyes
- moon lantern
- gentle / curious / dreamy personality

### 3D language
Approved direction:
- collectible-toy product rendering
- simplified smooth molded forms
- real-world manufacturable materials
- painted PVC / ABS / resin
- clear resin / transparent PVC
- plated plastic / metal-like accessory parts

### Outfit series
Approved principle:
- same IP, clearly different themed looks
- variation through silhouette + role + prop / mood
- not just recoloring the same dress
- each look should change 2–3 meaningful dimensions

### Background system
Approved principle:
- not pure color
- not a full illustration scene
- maximum 3 background element categories
- lower detail / contrast / saturation than the character
- character can remain moderate in scale and still dominate through hierarchy

### 2D asset translation
Approved principle:
- simplify rather than imitate 3D literally
- keep jellyfish dome + stars + lavender hair + face identity
- reduce glossy highlights, micro-jewelry and excessive ruffles
- use clean flat asset families for stickers / packaging / badges

### Logo direction
Approved as a **direction**, not a final locked brand mark:
- working title: Jellyfish Star / 水母星守
- soft flowing rhythm
- jellyfish / star symbol integration
- blue-violet + warm cream-yellow
- keep typography readable and restrained

### Poster / KV
Approved:
- character-led
- crescent / moon as one main story symbol
- restrained environment
- large negative space
- title-only or minimal typography

### Merchandise
Approved:
- route different assets to different product types
- do not paste the same full-body character onto everything
- use physically plausible materials

### Offline
Approved direction:
- Dream Trench world translated into buildable retail / exhibition space
- hero installation + product display + photo / interaction
- acrylic / polycarbonate / FRP / MDF / metal / LED rather than impossible fantasy architecture

# 3. Improve

These items are not blockers, but should be refined before a public v1.0 case release.

## A. Turnaround consistency
Current turnaround is still a candidate.

Need:
- stricter hidden-area construction
- less decoration drift between views
- clearer back / side manufacturing logic
- same accessory count and size in all views

## B. Expression asset bookkeeping
The visual direction is validated, but prompt / asset records contain several failed and intermediate attempts.

Need:
- designate one final approved expression grid
- archive rejected expression attempts clearly
- ensure the approved image has one matching canonical prompt record

## C. Action sheet
The workflow concept is validated, but the dedicated action-sheet deliverable should be regenerated later as a clean standalone 3×3 board.

Need:
- same outfit
- same studio field
- body-action changes only
- no scene or prop drift

## D. Final name
`Jellyfish Star / 水母星守` remains a working title.

Do not permanently bind the identity to it until the user selects:
- final Chinese name
- final English name
- optional companion name

## E. Logo finalization
Logo direction is usable, but a real final mark still needs:
- final typography lockup
- small-size test
- monochrome test
- icon-only test
- Chinese / English spacing test

# 5. Reuse

The strongest reusable lessons from this project should be promoted to the Skill.

## Reference handling
A reference can be:
- visually successful
- structurally wrong for the current task

Do not discard the whole reference.
Extract the successful visual language and reapply it under correct task constraints.

## Prompt traceability
Every generated visual should have:
- asset ID
- status
- canonical prompt
- reference role
- repair delta
- learning note

## Background restraint
Use:
```text
character > outfit / prop > environment
```

If crowded:
1. remove background elements;
2. reduce repeated symbols;
3. merge small elements into one large simple mass;
4. preserve whitespace.

## Material realism
For 3D collectible outputs:
- map fantasy visuals to real materials
- prioritize moldability / assembly / surface finish
- avoid undefined AI-only materials

## Outfit diversity
Do not hard-code nine outfits.
Generate variation from:
- role
- silhouette
- layering
- headwear
- footwear
- prop
- mood
- season
