# Jellyfish Star Guardian Reference Map

## REF-01 — Collectible-toy 3D reference

**Role:** overall 3D product language  
**Priority:** primary  
**Used in stage:** character final / all 3D outputs

### Learn
- simplified smooth shapes
- clean commercial collectible-toy presentation
- physically plausible molded forms
- soft studio lighting
- limited details
- subject remains visually dominant even at moderate scale

### Do not inherit
- source character identity
- source costume
- source logo
- source flowers / props
