# Series Outfit & Background Rules v0.4

> For outfit grids, blind-box series and themed character collections.
> The goal is: **same IP, clearly different looks, restrained backgrounds, character-first composition.**

---

# 1. Outfit series must not be hard-coded

Do **not** store nine fixed outfits in the Skill.

Generate outfits dynamically from:
- the current IP world;
- the current series theme;
- user-provided clothing references;
- commercial application.

The Skill should preserve a reusable method, not a permanent wardrobe.

---

# 2. Meaningful outfit variation

Each look should differ in at least **2–3 meaningful dimensions**:

- silhouette;
- layering;
- role / identity;
- headwear;
- footwear;
- handheld prop;
- accessory family;
- mood;
- season / context.

Good:

```text
rain patrol:
short translucent rain cape
+ boots
+ umbrella
+ curious mood
```

Bad:

```text
same ruffle dress
+ different color
+ different pose
```

The user should read the grid as a **collectible series**, not repeated styling.

---

# 3. Character identity stays locked

Outfit variation must not accidentally change:
- face;
- eye design;
- head/body proportion;
- species;
- core head construction;
- primary symbol;
- approved material language.

Clothing changes. The IP does not.

---

# 4. Background is support, not the subject

The background exists to:
- explain theme;
- separate the silhouette;
- create commercial atmosphere.

It must not become a full illustration scene that competes with the character.

Visual priority:

```text
character
> outfit / prop
> environment
```

---

# 5. Background element limit

Per image:

**maximum 3 background element categories.**

Recommended:

```text
1 environment cue
+ 1 support object
+ 1 atmospheric element
```

Examples:

### moon-night
- crescent moon
- soft cloud mass
- sparse star light

### rain
- rain streaks
- wet ground
- one distant soft architectural cue

### shell
- one shell seat
- few pearls
- soft bubbles

### explorer
- one rock / pier
- distant horizon
- one navigation object

Do not count the character's handheld prop as background.

---

# 6. Background restraint rules

Background should usually be lower than the character in:
- contrast;
- saturation;
- sharpness;
- detail density;
- object count.

Use:
- large simple shapes;
- soft depth blur;
- controlled negative space;
- simple ground / pedestal;
- one clear environment clue.

Avoid:
- many tiny objects;
- repeated glowing ornaments;
- multiple buildings;
- decorative clutter around the head;
- high-detail scenery behind the face;
- filling empty space just because it exists.

---

# 7. Character does not need to be huge

A smaller character can still dominate when:
- silhouette is clean;
- background is quiet;
- color contrast is controlled;
- the face has clear space around it;
- props do not compete.

Do not solve weak focus by endlessly enlarging the character.

Solve the hierarchy first.

---

# 8. Real-world material rule

For 3D collectible / blind-box outputs, describe materials that exist in real production.

Preferred examples:
- painted PVC;
- ABS;
- cast resin;
- transparent PVC;
- clear resin;
- acrylic;
- flocking;
- fabric;
- metal-plated accessory;
- pearl coating;
- matte paint;
- gloss varnish.

Avoid vague impossible AI materials such as:
- liquid crystal dream skin;
- magical translucent fabric with no physical construction;
- light made into solid cloth;
- undefined glass-gel body materials.

If a visual effect is needed, translate it into a real production method.

Example:

```text
not: glowing jelly dress
use: translucent clear-PVC skirt with pearlescent coating and internal warm LED-like lighting only in display mockup
```

---

# 9. 3:4 outfit grid recommendation

For a 3x3 series board:
- total board ratio: 3:4;
- each cell composition should feel consistent;
- character scale should stay within a narrow range;
- background complexity should remain consistently low;
- each cell may have a different environment cue, but not a fully different world.

The result should resemble a clean collectible-series catalog.

---

# 10. Self-review before delivery

Check:

1. Is it still the same IP across all nine?
2. Are the outfits actually different?
3. Does each look have a clear role / theme?
4. Are any backgrounds more interesting than the character?
5. Does any cell contain more than 3 background element categories?
6. Are there unnecessary tiny decorations?
7. Are materials physically believable?
8. Is the character still readable when viewed as a small thumbnail?
9. Is negative space being used intentionally?
10. Does the grid feel like a product series instead of nine illustrations?

If 4, 5 or 6 fail:
**remove background elements before changing the character.**
