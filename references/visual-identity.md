# Visual Identity

Character DNA and Visual DNA are separate systems.

Character DNA answers: **what makes the character itself the same character?**

Visual DNA answers: **what makes every communication piece feel like the same brand world?**

## 2D Asset System

Before heavy applications, translate the character into useful graphic assets:
- avatar;
- half-body;
- full-body;
- flat illustration;
- line version;
- monochrome version;
- sticker cutout;
- recurring icons;
- super-symbol.

Do not flatten by merely tracing the 3D render. Rebuild the same identity in a graphic language.

## Logo

Use AI for route exploration and image ideation, but preserve a path to production cleanup.

Explore:
- wordmark;
- emblem;
- character mark;
- symbol lockup.

Evaluate:
- recognition;
- small-size legibility;
- silhouette;
- relationship to super-symbol;
- compatibility with the character system.

## Typography

Treat typography as a role system:
- display;
- supporting;
- body;
- numeric / utility if needed.

Reference analysis should extract visible traits such as weight, width, curvature, rhythm, and spacing rather than copy a proprietary wordmark.

## Color

Define roles, not just swatches:
- character base;
- identity color;
- supporting color;
- neutral;
- campaign accent.

## Graphic language

Define:
- recurring shapes;
- icon style;
- border/outline logic;
- pattern;
- symbol language;
- grid and spacing behavior.

## Gate D

Visual DNA v1 is ready when logo, type, colors, and graphic elements work together and can support campaign and merchandise without redesigning the character.
