# QA & Project Review

Use this module after major batches and at final handoff.

## Batch QA

### Character
- identity preserved?
- proportions stable?
- face placement stable?
- colors stable?
- props remain correct scale?
- material consistent?

### Visual identity
- correct Visual DNA version?
- typography role consistent?
- logo consistent?
- color roles intact?
- graphics feel from one system?

### Applications
- asset type appropriate for medium?
- readable hierarchy?
- no random decorative drift?
- reference translated rather than copied?
- output usable at the requested ratio/format?

## Final review framework

### Keep
What is already strong and should remain locked?

### Improve
What is inconsistent, weak, overcomplicated, generic, or under-resolved?

### Extend
What new characters, stories, seasons, merchandise or environments can grow naturally from the existing system?

### Reuse
Which rules, prompt patterns, reference strategy, QA checks, or folder conventions are reusable in the next IP project?

## Final case study should show

1. problem / seed idea;
2. references and extracted logic;
3. five concept directions;
4. chosen concept and brief;
5. sketch exploration;
6. Character Master;
7. turnaround;
8. expressions/actions;
9. outfit system;
10. 2D assets;
11. visual identity;
12. campaigns;
13. merchandise;
14. offline experience;
15. review and next opportunities.
