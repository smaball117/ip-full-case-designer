# Concept Direction

Concept exploration answers **who the IP is**, not merely what color it wears.

## Five-direction requirement

Each direction must include:
- concept name;
- one-line world premise;
- character role;
- 3–5 personality traits;
- one useful flaw or tension;
- meaning of the super-symbol;
- recurring behavior;
- visual keywords;
- likely commercial extensions;
- one tradeoff.

Directions must not be color swaps.

At least three structural dimensions must differ between any two directions.

## Deep Brief after selection

Complete only after Gate A.

Recommended fields:
- project / IP name;
- one-line story;
- world rules;
- protagonist role;
- personality;
- flaw;
- desire;
- fear/dislike;
- ability;
- recurring action;
- primary super-symbol;
- secondary symbols;
- primary and supporting colors;
- target audience;
- intended touchpoints;
- must-keep;
- must-avoid.

## Creative test

A concept is ready for sketching when:
1. its core symbol has a reason to exist;
2. its personality can create expressions and actions;
3. its world can create outfits, posters or events;
4. it can be recognized without a long explanation.
