# Character Design System

This module covers sketch exploration, Character Master, turnaround, expressions, actions, and outfits.

## A. Sketch Exploration

Generate five form explorations inside the same approved concept.

Vary:
- head silhouette;
- body proportion;
- ear/hair/horn placement;
- signature headwear;
- symbol placement;
- accessory relationship.

Keep:
- species or core entity;
- selected world premise;
- core super-symbol;
- major personality direction.

The goal is to compare silhouettes and recognition, not render quality.

## B. Character Master

Selected sketch becomes v0.

Refine into the master image and validate:
- silhouette;
- head/body ratio;
- face location;
- expression system;
- color hierarchy;
- material;
- signature prop scale;
- accessory logic;
- recognizability at small size.

After approval, write Character DNA v1.

## C. Turnaround

Default: front / side / back. Add 3/4 hero view when useful.

Rules:
- same scale;
- same proportions;
- same costume and props;
- no redesign between views;
- back view must explain hidden construction;
- side view must explain depth, not just rotate the face.

## D. Expression Sheet

Expressions are personality tests, not only mouth swaps.

Keep identity fixed and change:
- eyebrow angle;
- eye shape;
- mouth;
- cheek treatment;
- head tilt;
- small pose cue.

Build expressions that belong to this character's world.

## E. Action Sheet

Use recurring behaviors from the brief.
Actions should reveal character and create future sticker/poster assets.

## F. Outfit Translation

When the user supplies clothing references:

Extract:
- silhouette;
- layering;
- palette;
- material cue;
- one or two key accessories.

Then translate into the IP's shape language:
- simplify;
- shorten;
- round;
- reduce folds;
- preserve Character DNA;
- keep core recognition visible.

Do not copy the reference model's face, body, photography, or unrelated styling.

## Prompt discipline

When an approved reference exists, prefer:

```text
LOCKED CHARACTER:
use approved master / Character DNA v1

CHANGE ONLY:
[expression / pose / outfit / camera]

PRESERVE:
[critical identity traits]
```

Avoid rewriting the entire style paragraph on every generation.
