# Application System

Applications are downstream expressions of locked Character DNA and Visual DNA.

## Campaign / Poster

When references are supplied, analyze:
- hierarchy;
- grid;
- title scale;
- character scale;
- negative space;
- color distribution;
- density;
- relationship between type and illustration.

Create one hero KV before a series.

Do not confuse "same layout" with "same style". Extract the structure and rebuild with the active IP system.

## Merchandise

Start with a focused set.

Use the right asset type:
- 3D master for figure/collectible visualization;
- 2D full body for prints;
- icons/patterns for repeat surfaces;
- logo for brand lockups;
- stickers for small accessories.

Avoid putting the same full character on every object.

## Offline Experience

Resolve the context first:
- indoor;
- outdoor;
- market;
- pop-up;
- exhibition.

Then define:
1. theme;
2. visitor journey;
3. hero installation;
4. supporting touchpoints.

Typical touchpoints:
- entrance / arch;
- main backdrop;
- photo spot;
- display counter;
- wayfinding;
- interactive device;
- floor / hanging graphics;
- retail or giveaway zone.

The theme should come from the IP world, not from random decoration.
