# Campaign System

## Process

1. choose a theme from Theme Engine;
2. choose a layout preset;
3. choose one narrative moment;
4. define one hero symbol state;
5. write title hierarchy;
6. generate hero KV;
7. QA against Visual DNA;
8. only then expand into series.

## Campaign brief

Every KV should state:
- theme
- narrative node
- emotional goal
- hero action
- hero symbol
- layout preset
- ratio
- text allowance
- density limit

## Rule

Do not start with "make it like reference X".

If a reference is supplied, it may influence only a named variable.
