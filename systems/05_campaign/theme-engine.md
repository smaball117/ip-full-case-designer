# Theme Engine

Campaign themes must be derived from the IP's narrative engine.

## Theme formula

```text
Narrative node
+ emotional need
+ one super-symbol state
+ one action
= campaign theme
```

## Generate 3 levels

### Core brand theme
Explains what the IP is.

### Seasonal / event theme
Uses the same world under a time or occasion.

### Content theme
Small repeatable social stories.

## Originality test

Before approving a theme, ask:
1. Could this theme exist without the reference image?
2. Does it reveal a world rule or personality trait?
3. Does it create at least three follow-up assets?
4. Is the character still the primary reason the theme exists?

If not, the theme is probably reference-led rather than IP-led.
