# Visual DNA System

Visual DNA defines how the entire IP communicates beyond the character itself.

## Required layers

- illustration language
- color roles
- typography roles
- logo logic
- symbol language
- line / outline rules
- graphic elements
- composition density
- character scale
- background complexity
- spacing / negative space
- image hierarchy

## Rule

Do not define Visual DNA with adjectives only.

Bad:
- cute
- trendy
- playful

Better:
- thin orange-red outline
- flat fills only
- no gradients
- hero character occupies 45–60% of KV
- supporting symbols <= 5
- 30% clean space around face
- sky blue is the dominant field color

## Gate D

Visual DNA is lockable only when the rules can produce:
1. a poster;
2. a logo lockup;
3. a sticker;
4. a merchandise graphic;
without a new external reference.
