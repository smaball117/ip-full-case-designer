# Illustration System

Define the rendering language independently from subject matter.

## Specify

- 2D / 3D / hybrid
- outline color and thickness
- fill behavior
- gradient policy
- shadow policy
- texture policy
- material cue
- perspective
- facial rendering
- prop detail level
- background detail level

## Consistency rule

The same character can exist in 3D and 2D, but both must preserve Character DNA.

A 2D version should be redesigned for graphic clarity, not traced mechanically from 3D.
