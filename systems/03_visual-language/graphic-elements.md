# Graphic Elements System

Build a small repeatable kit.

## Categories

- super symbol
- secondary symbols
- frames
- badges
- arrows
- dividers
- labels
- patterns
- state icons

## Constraint

Every project should define a maximum decorative density.

Default recommendation:
- hero KV supporting symbols <= 5
- no more than 2 decorative families in one composition
- no decoration within the face-protection zone unless intentional

## Rule

If a decorative element does not communicate world, brand, hierarchy, or interaction, remove it.
