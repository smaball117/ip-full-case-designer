# Typography System

Typography is a reusable role system, not a one-off logo imitation.

## Roles

- Brand wordmark
- Campaign display
- Supporting display
- Body / utility
- Numerals / labels if needed

## Extractable traits

When references are used, learn only:
- weight
- width
- curvature
- rhythm
- baseline behavior
- spacing
- terminal shape
- outline logic

Do not copy proprietary lettering.

## Output

Define:
- allowed weight range
- allowed curvature
- outline / fill relationship
- line count preference
- maximum supporting copy
- whether decorative icons may enter letterforms

## Text discipline

For image generation:
- prefer title + one short brand line;
- prohibit filler microcopy unless explicitly requested;
- never auto-generate decorative small text.
