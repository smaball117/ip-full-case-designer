# Color System

Define colors by role and proportion.

## Required roles

- field / background
- character base
- identity color
- warm accent
- cool accent
- neutral
- utility / state colors

## Ratio guidance

Use approximate ratios rather than rigid hex-only thinking.

Example:
```text
field 45–60%
character base 20–30%
identity color 10–15%
accent 5–10%
utility <5%
```

## State colors

If the world has state changes, define them here.

Example:
- success
- failure
- inactive
- warning
- reward

State colors must not accidentally replace the brand identity color.
