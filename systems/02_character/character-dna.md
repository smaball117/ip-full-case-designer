# Character DNA System

Character DNA is a rule set, not a paragraph.

## Required fields

### Identity
- name
- species / entity
- role
- personality triangle
- flaw

### Silhouette
- head shape
- head/body ratio
- body shape
- limb proportions
- ear / hair / horn placement
- tail logic

### Face
- feature zone
- eyes
- pupils
- highlights
- eyebrows
- nose
- mouth
- cheeks / marks

### Signature
- primary symbol
- headwear
- bow / accessory
- prop hierarchy
- color hierarchy
- material

### Scale rules
Define relative scale for:
- head
- torso
- hands/feet
- main prop
- secondary props

## Locked vs flexible

### Locked after Gate C
- core silhouette
- face construction
- identity colors
- primary symbol
- signature accessory logic

### Flexible
- expression
- pose
- outfit
- small prop
- scene
- campaign styling

## Prompt principle

Downstream prompts should say:
```text
LOCK Character DNA vX
CHANGE ONLY: ...
```

Do not restate the entire character unless a tool requires it.
