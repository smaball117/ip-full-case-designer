# Shape Grammar

Shape Grammar defines how every new form should feel related to the character.

## Define

- dominant primitive: circle / oval / rounded rectangle / bean / other
- corner language
- taper language
- symmetry preference
- softness
- thickness
- detail density
- silhouette complexity

## Translation rules

Any new object, outfit or accessory should be translated through the active shape grammar.

Example:
- sharp buckle → rounded chunky buckle
- long thin wand → short thick rounded wand
- detailed ruffle → one or two simplified scallops

## Test

If an accessory looks like it came from another franchise after the character is removed, simplify and retranslate it.
