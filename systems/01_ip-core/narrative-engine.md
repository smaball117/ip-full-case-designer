# Narrative Engine

The Narrative Engine converts world rules into repeatable story loops.

## Base loop

Build a loop in this form:

```text
TRIGGER
↓
TASK
↓
ATTEMPT
↓
SUCCESS or FAILURE
↓
VISIBLE STATE CHANGE
↓
REWARD / REPAIR
↓
NEXT STORY
```

## Why this matters

Campaign themes should come from the narrative loop, not from whatever reference image is currently being used.

## Theme extraction

For every node in the loop, generate:
- 3 campaign concepts;
- 3 content ideas;
- 2 merchandise ideas;
- 1 offline interaction.

## Example pattern

```text
collect → classify → attempt → fail → repair → complete → celebrate
```

This can become:
- collection station;
- repair room;
- graduation night;
- reward delivery;
- archive day.

The visual system remains stable while the narrative state changes.
