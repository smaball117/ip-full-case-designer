# IP Strategy System

This module defines the strategic core of an IP before visual execution.

## Required outputs

Every project should resolve:

- **Core Promise** — what emotional or functional value the IP consistently gives people.
- **Emotional Value** — the feeling users should take away.
- **Personality Triangle** — three traits that create behavior, not just adjectives.
- **Useful Flaw** — a weakness that creates stories, humor, or empathy.
- **Super Symbol** — one primary symbol with narrative meaning.
- **World Role** — what the character does in its world.
- **Audience** — who the IP is designed to resonate with.
- **Commercial Territory** — where the IP can naturally extend.
- **Must Avoid** — what would dilute the identity.

## Rule

Do not move from a loose idea directly into image prompting.

Convert the brief into structured decisions first.

## Readiness test

The IP core is ready when:
1. the character can be explained in one sentence;
2. the primary symbol has a narrative function;
3. personality predicts behavior;
4. the flaw creates recurring situations;
5. at least three application territories feel natural rather than forced.
