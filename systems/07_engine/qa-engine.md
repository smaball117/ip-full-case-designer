# QA Engine

QA is a gate, not a final afterthought.

## Scores

Score 0–2 for each dimension:

### Identity
- Character DNA preserved
- super-symbol correct
- personality readable

### Visual system
- color roles correct
- typography role correct
- outline / illustration rules correct
- density within limits

### Composition
- chosen layout preset respected
- hierarchy clear
- enough negative space
- face not obstructed

### Originality
- not overly dependent on reference
- theme comes from world rules
- no borrowed distinctive motifs

### Production
- ratio correct
- text policy correct
- asset usable for intended application

## Decision

- 90%+ pass
- 75–89% targeted repair
- below 75% regenerate from the smallest failing layer

Do not solve QA failure by making the prompt longer by default.
