# Merchandise System

Merchandise should express the IP system, not merely print the full character everywhere.

## Asset routing

Use:
- Character Master for figures / collectible visualization
- simplified full-body art for apparel / print
- super-symbol for small products
- icons / patterns for repeat surfaces
- wordmark for brand lockups

## Product concept rule

Every merchandise concept should answer:
1. why this product belongs to the IP world;
2. which symbol or behavior it expresses;
3. which asset type is best for the surface.

## Density

Small objects require simpler graphics.
Do not shrink a complex poster onto a small product.
