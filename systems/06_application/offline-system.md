# Offline Experience System

Offline design begins with a world experience, not a list of fixtures.

## Process

1. choose one narrative theme;
2. define visitor action;
3. define hero installation;
4. define 3–6 supporting touchpoints;
5. route each touchpoint to the correct Visual DNA asset;
6. verify the visitor can understand the IP without reading a long explanation.

## Common experience types

- indoor pop-up
- outdoor activation
- market / fair
- exhibition
- retail corner

## World-first rule

Example:
wish collection world → check-in counter / wish deposit / success-star lighting interaction.

Do not decorate a generic booth with random apples and call it an IP space.
