# Layout Grammar

A mature IP needs reusable composition logic.

## Core rule

Do not use a reference image as the default layout engine.

Choose a named layout preset first, then adapt to the requested ratio.

## Composition variables

- title zone
- character zone
- symbol zone
- negative-space zone
- background zone
- information density
- visual reading order

## Face protection zone

Keep a clean area around the character's face.
Default: no large props or text overlapping the face unless the concept depends on it.

## Ratio adaptation

A preset should define how it behaves in:
- 3:4
- 1:1
- 16:9
- 9:16

Do not fill extra width or height with random elements.
