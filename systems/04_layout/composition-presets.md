# Composition Presets

Use these as starting grammars, not fixed templates.

## L01 — Hero Center
- title top
- one large character center / lower center
- supporting symbols sparse
- best for: master KV, launch poster

## L02 — Character Left
- character 45–55% left
- title / message on right
- best for: horizontal KV, campaign

## L03 — Character Right
- mirrored L02
- best for: editorial series

## L04 — Symbol Hero
- one oversized super-symbol
- smaller character interacting with it
- best for: world-rule storytelling

## L05 — Story Scene
- one character
- one location
- one action
- background simplified
- best for: campaign narrative

## L06 — Collection Grid
- repeated same character
- expressions / outfits / actions
- equal cell logic
- best for: system boards

## Density rule

A preset should never force more objects merely because the canvas is larger.
