## Reference handling rules

1. Keep the latest approved character image as the primary identity anchor after Gate C.
2. Add task-specific references only for the current variable.
3. If references conflict, follow explicit user priority first.
4. A new outfit, poster or typography reference must not silently redesign the character.
5. Mark superseded references instead of deleting their history.
